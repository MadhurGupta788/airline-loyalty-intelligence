## Problem

Airlines invest heavily in loyalty programs, yet most react too late — high-value customers go silent long before formally cancelling. This project builds a proactive, data-driven loyalty intelligence system over ~16,700 Canadian loyalty members (2012–2018) to answer:

- Which members are likely to disengage, and when?
- Which members are genuinely valuable, not just historically?
- What specific retention interventions should marketing act on?

---

## Key Results

- **XGBoost AUC-ROC: 1.0000** vs Logistic Regression baseline: 0.9998
- **Top churn driver:** Recency of last flight (51.4% feature importance)
- **0 false negatives** — all 51 churned members in test set correctly identified
- **5 customer segments** identified with distinct behavioral profiles
- **Highest priority segment:** Dormant High-Value (1,937 members, avg CLV CAD 8,071, 13% churn rate)

## Approach

### Churn definition
Two competing definitions built and compared in `01_eda.ipynb`:
- **Definition A (formal):** explicit membership cancellation — 2,067 members (12.4%)
- **Definition B (behavioral):** active in H1 2017 but zero flights from Jul 2017 onward — 257 members (1.5%) ← *primary label*

Definition B is preferred because it captures silent disengagement before formal cancellation.

### Modelling
- Baseline: Logistic Regression (AUC 0.9998)
- Primary: XGBoost (AUC 1.0000) with class weighting for imbalance
- Feature importance via XGBoost built-in gain metric

### Segmentation
K-means (k=5) on 8 behavioral features, profiled against CLV and churn risk to produce actionable marketing segments.
